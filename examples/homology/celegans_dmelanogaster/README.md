# C. elegans–D. melanogaster BLASTP homology example

This example demonstrates how to infer cross-species homologous gene relationships from complete protein FASTA files and export a TACMAN-compatible three-column homology file.

## Species and data source

Reference species: Caenorhabditis elegans  
Query species: Drosophila melanogaster  
Data source: Ensembl release 115  

Reference proteome: 31,865 protein sequences  
Query proteome: 30,802 protein sequences  

## Workflow overview

The full workflow consists of:

1. downloading complete protein FASTA files from Ensembl release 115;
2. preparing protein-to-gene mapping tables;
3. building BLAST databases with `makeblastdb`;
4. running bidirectional BLASTP;
5. filtering BLASTP hits by e-value, amino-acid identity, and query coverage;
6. retaining top-N hits;
7. identifying reciprocal best hits;
8. mapping protein-level relationships to gene-level relationships;
9. exporting a TACMAN-compatible three-column homology file.

## Main parameters

E-value threshold: 1e-5  
Minimum amino-acid identity: 30%  
Minimum query coverage: 50%  
Top-N hits retained per query protein: 5  
CPU threads: 16  

In our test environment, the complete workflow took 39 min 31.68 s using 16 CPU threads, with peak memory usage of approximately 431 MB.

## Download FASTA files

Run:

```bash
bash examples/homology/celegans_dmelanogaster/download_ensembl115_fasta.sh
```

This downloads complete protein FASTA files from Ensembl release 115 into:

```text
examples/homology/celegans_dmelanogaster/raw/
```

## Run the full BLASTP homology workflow

Run:

```bash
bash examples/homology/celegans_dmelanogaster/run_full_blast_example.sh
```

This script wraps a single `prepare_homology.py --mode blast` command. The expected output is:

```text
examples/homology/celegans_dmelanogaster/ortholog/C_elegans_to_D_melanogaster.txt
```

The output file is a TACMAN-compatible three-column homology mapping file.

## How to adapt this example to another species pair

To use a different species pair, modify the following items.

### Species names

Edit these arguments in `run_full_blast_example.sh`:

```text
--sp-ref
--sp-que
--query-display-name
```

Use short, file-safe species identifiers, such as `human`, `mouse`, `C_elegans`, or `D_melanogaster`.

### FASTA download URLs

Edit:

```text
download_ensembl115_fasta.sh
```

Replace the Ensembl protein FASTA URLs with the URLs for the new reference and query species. When possible, keep the same Ensembl release for both species to ensure that FASTA files and annotation files are version-matched.

### FASTA file paths

Edit these arguments in `run_full_blast_example.sh`:

```text
--ref-protein
--que-protein
```

These paths should point to the downloaded reference and query protein FASTA files.

### Protein-to-gene mapping files

Prepare two tab-delimited mapping files:

```text
reference_protein_to_gene.tsv
query_protein_to_gene.tsv
```

Each mapping file should contain at least a `protein_id` column and a gene identifier column. The protein identifiers in the mapping files must match the protein identifiers in the FASTA headers.

Edit these arguments:

```text
--ref-id-map
--que-id-map
--ref-protein-id-column
--que-protein-id-column
```

If the mapping files use different column names, modify the corresponding column-name arguments.

### Output paths

Edit these output arguments to avoid overwriting previous runs:

```text
--out
--blast-workdir
--register-info
```

### BLAST filtering parameters

The example uses:

```text
--evalue 1e-5
--min-pident 30
--min-qcov 50
--top-n 5
--threads 16
```

For closely related species, stricter thresholds may be appropriate. For more distant species, users may need to relax filtering thresholds. BLASTP-derived relationships should be interpreted as putative sequence-similarity-based homology relationships rather than curated phylogenetic orthology.

## Post-processing existing BLASTP outputs

The files `configs/celegans_dmelanogaster.yaml` and `configs/blast_postprocess_example.yaml` illustrate `blast-postprocess` mode after bidirectional BLASTP outputs have already been generated. The full FASTA-to-homology example is provided by `download_ensembl115_fasta.sh` and `run_full_blast_example.sh`.

## Notes

Full protein FASTA files, BLAST databases, and full BLASTP output files are not included in the repository because of file size. They can be regenerated by running the download and BLAST scripts above.
